## 简介
本系统是一个基于 RimWorld 的 NPC 剧情生成框架，专注于提示词管理与 LLM 采样控制。系统通过三个核心角色实现分层叙事：导演（Director）负责事件路由与剧情规划，编剧（Screenwriter）负责具体场景的台词创作，临时工（Freelancer）负责突发性事件的即时响应。每个角色都配有专门的提示词模板，支持动态参数替换和上下文注入。

## 核心组件
系统的核心由三个主要组件构成：

### PromptConfig - 提示词配置管理
负责管理所有角色的提示词配置，包括默认值加载、动态修改和持久化存储。

### DriverConfig - 驱动配置管理  
控制事件池触发阈值、定时器脉冲等运行时参数。

### WorkspaceImpl - 工作空间实现
处理具体的叙事操作，包括台词推送和轮次结束。

### 角色专用提示词模板

#### 导演 Agent 提示词
导演负责整体剧情规划和事件路由，其提示词强调：
- 事件审查与筛选
- 剧情线选择与路由
- 工作空间管理（创建、分支、合并）

#### 编剧 Agent 提示词  
编剧专注于具体场景的创作，要求：
- 事件上下文获取
- 台词逐句创作
- 轮次总结与收尾
- 与导演的协作沟通

#### 临时工 Agent 提示词
临时工处理突发性事件，特点：
- 独立任务处理
- 即时响应能力
- 轻快叙事风格
- 事件重新路由

## 性能考虑
系统在设计时充分考虑了性能优化：

### 内存管理
- 使用 StringBuilder 减少字符串拼接开销
- JsonWriter 采用结构体避免堆分配
- 懒加载机制减少初始化时间

### 缓存策略
- 提示词内容缓存在静态字段中
- 避免重复的文件读取操作
- 嵌入式资源的高效访问

### 序列化优化
- 批量写入减少内存分配
- 条件属性写入避免空值处理
- 类型安全的数值格式化

## 故障排除指南

### 常见问题诊断
1. **提示词加载失败**
   - 检查嵌入式资源路径是否正确
   - 验证资源文件是否包含在程序集中
   - 查看异常信息确认具体错误原因

2. **JSON 序列化异常**
   - 确认 JSON 格式符合预期
   - 检查特殊字符转义是否正确
   - 验证数值格式的文化设置

3. **工作空间操作失败**
   - 检查调用者权限是否正确
   - 验证工作空间状态是否活跃
   - 确认参数验证是否通过
